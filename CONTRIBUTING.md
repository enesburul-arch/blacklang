# Contributing to BlackLang

BlackLang is currently in the foundation stage.

## Priorities

The project should prioritize:

- AI-readable syntax
- Deterministic compiler behavior
- Clear JSON diagnostics
- Small, testable language increments
- Web application generation first

## Contribution Rules

- Keep changes focused.
- Update `SPEC.md` when language syntax changes.
- Add examples when adding language features.
- Add tests when compiler behavior changes.
- Do not add new dependencies without a clear reason.
